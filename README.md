# Análise de Arboviroses em Santana do Paraíso (MG)

Trabalho acadêmico de Engenharia de Software que organiza uma série semanal de dengue e chikungunya em Santana do Paraíso (MG), junto com variáveis climáticas, para análise exploratória.

## Dados

- **Período:** 105 semanas epidemiológicas (SE 1/2024 a SE 53/2025)
- **Município:** Santana do Paraíso (código IBGE 3158953)
- **Fonte:** InfoDengue (https://info.dengue.mat.br)

## Variáveis

| Código | Variável | Origem |
|---|---|---|
| Y1 | Casos de dengue | InfoDengue |
| Y2 | Casos de chikungunya | InfoDengue |
| X1 | Precipitação acumulada (mm) | **Simulada** |
| X2 | Temperatura média (°C) | InfoDengue |
| X3 | Umidade relativa do ar (%) | InfoDengue |
| X4 | Cobertura de saneamento/esgoto (%) | **Simulada** |

> **Atenção:** X1 e X4 são dados simulados para fins didáticos e não representam valores oficiais.

## Resultados observados

- Chikungunya: 1.299 casos no período (1.283 em 2024 e 16 em 2025)
- Dengue: 1.344 casos no período (1.244 em 2024 e 100 em 2025)
- 2024 concentrou a epidemia, com queda forte em 2025
